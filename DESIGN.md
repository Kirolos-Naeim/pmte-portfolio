# PMTE Portfolio Design System

## Brand direction

PMTE is presented as an established Abu Dhabi field contractor: disciplined, technically capable and direct. The interface uses hard-edged rectangular geometry, visible alignment, fine rules and controlled contrast. Decorative effects are avoided.

## Core palette

| Token | Value | Use |
|---|---:|---|
| Near black | `#151515` | Covers, dark sections, primary text |
| Industrial red | `#D71920` | Brand emphasis, key rules, action and status accents |
| White | `#FFFFFF` | Primary background and reversed text |
| Light grey | `#F3F4F6` | Project and supporting sections |
| Charcoal | `#262626` | Secondary dark text |
| Steel grey | `#667085` | Metadata, supporting copy and technical labels |

Red is used sparingly. The interface contains no decorative gradients; only functional photographic overlays are used to protect text contrast.

## Typography

- Primary: Geist Sans with Arial/Helvetica fallbacks.
- Technical labels: Geist Mono with monospace fallback.
- Headings use tight tracking, controlled uppercase and compact line height.
- Body copy uses generous line height and conservative measure.
- No paragraph should exceed approximately 75 characters per line on large screens.

## Layout

- Maximum content width: 1,500 px.
- Desktop section spacing: 112 px vertical with fluid horizontal margins.
- Main grid: 12-column intent expressed through two-, three- and four-column components.
- Tablet: reduce three/four-column groups to two columns.
- Mobile: single-column content with two-column statistical and image groups where legible.
- All images use fixed aspect-ratio containers and `object-fit: cover` to prevent distortion.

## Components

- Cover: full-bleed field photograph, near-black overlay, compact metadata tag, strong title and evidence-based statistics.
- Section marker: numbered technical label above a fine divider.
- Capability card: bordered rectangle with numeric index, title and concise copy.
- Project case study: photograph, sector, project name, location and defined scope.
- Credential table: explicit issue date, expiry date and current/status treatment.
- Historical notice: clearly separated from current credentials.
- Gallery: filterable image archive with keyboard-accessible lightbox controls.
- Contact block: direct contact data and explicit placeholders for unconfirmed details.

## Logo approach

The balanced identity sits between the former minimal badge and the supplied complex construction illustration. It retains a concise PMTE wordmark and one restrained equipment/pipe emblem. It removes the refinery skyline, multiple machines and decorative arcs so the mark stays legible at navigation, document and favicon sizes.

## Print system

- Target: A4 portrait.
- Page margin: 12 mm.
- Full cover and major achievement pages use controlled full-page layouts.
- Main sections begin on new pages.
- Cards, tables and gallery items avoid internal page breaks.
- Navigation, filters, interactive controls and lightbox UI are hidden in print.
- Colour reproduction uses `print-color-adjust: exact`.

## Content and compliance rules

- Use only verified source facts and user-supplied project names.
- No invented quantities, technical specifications, contract values, project metrics, testimonials or safety statistics.
- PMTE is described as associated with Modon Properties on the 2020 Guinness World Records demolition; never as sole record holder.
- Expired ISO and ICV evidence is labelled historical and never presented as current.
- Credentials are dated and must be revalidated before formal submission.
- No passport numbers, identity numbers, signatures, QR codes or private personnel information are published.
